This is an NEA project for a fluid simulation, designed specifically for aerofoils.

To get started download the project and open it in visual studio or your chosen IDE then ensure that python is installed, extract the zipped folder and open it locate the flowbench folder and open it in your IDE and run the installer.py program to install the dependencies.

Alternatively you can pull the project from github with a github extension on your chosen IDE and then run the installer.py.
